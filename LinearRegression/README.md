# Linear Regression

## Overview
This folder contains code for predicting a continuous numerical value using Linear Regression.

## Aim
To fit a Linear Regression model and evaluate how well it predicts a numerical target.

## Theory
Linear Regression models the relationship between input features and a continuous target by fitting a linear equation. In simple linear regression there is one input feature; in multiple linear regression there are two or more input features.

## General Procedure
1. Load the dataset.
2. Select the input features and continuous target variable.
3. Handle missing values and prepare the data as needed.
4. Split the dataset into training and testing sets.
5. Create and train the Linear Regression model.
6. Predict target values for the test set.
7. Compare predicted and actual values.
8. Evaluate the model with suitable regression metrics.

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Libraries
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn

## Conclusion
Linear Regression is a basic and interpretable method for estimating continuous values when a linear relationship is a reasonable approximation.
