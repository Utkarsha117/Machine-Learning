# Machine Learning

A collection of Jupyter notebooks covering data preprocessing, exploratory data analysis, dimensionality reduction, regression, and classification algorithms using Python.

## Project Overview

This repository contains practical notebooks for learning and experimenting with common machine-learning concepts and workflows. Each notebook focuses on a particular topic or algorithm, with examples and analysis.

## Repository Contents

| File | Description |
|---|---|
| `1_DataPreprocessing.ipynb` | Data cleaning and preparation, including missing values, duplicate records, categorical encoding, and feature scaling. |
| `2_EDA.ipynb` | Exploratory Data Analysis (EDA) to inspect data, summarize variables, and visualize patterns and relationships. |
| `3_PCA.ipynb` | Principal Component Analysis (PCA), a dimensionality-reduction technique for representing data with fewer features. |
| `4_LinearRegression.ipynb` | Linear Regression for exploring and modeling relationships between numerical variables. |
| `4_LogisticRegression.ipynb` | Logistic Regression for classification tasks. |
| `5_SVM.ipynb` | Support Vector Machine (SVM) classification concepts and implementation. |
| `6_KNN.ipynb` | K-Nearest Neighbors (KNN), a distance-based algorithm used for classification. |
| `7_ComparisonRegressionModel.ipynb` | Comparison of regression models. |
| `8_ClassificationAlgorithmsComparison.ipynb` | Comparison of classification algorithms. |
| `Employee.csv` | Employee dataset used by the notebooks where applicable. |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Utkarsha117/Machine-Learning.git
cd Machine-Learning
```

### 2. Install Python

Install Python 3 if it is not already installed.

### 3. Install common dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook you want to run and execute its cells in order.

Alternatively, open the repository folder in Visual Studio Code and use the Jupyter extension.

## Dataset Notes

Some notebooks may expect `Employee.csv` to be available in the current working directory. If a notebook uses a hard-coded local file path, update the path to match your computer. Dataset columns and preprocessing steps can differ by notebook.
