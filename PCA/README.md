# Principal Component Analysis (PCA)

## Overview
This folder contains code for reducing the number of dimensions in a dataset using PCA.

## Aim
To apply Principal Component Analysis and examine how a smaller set of components can represent variation in the original features.

## Theory
PCA is an unsupervised dimensionality-reduction technique. It transforms correlated numerical features into a smaller set of uncorrelated components, ordered by the amount of variance they explain.

## General Procedure
1. Load the dataset and select numerical features.
2. Handle missing values as required.
3. Standardize the features when they are measured on different scales.
4. Create a PCA model with the desired number of components or variance target.
5. Fit PCA to the prepared data and transform the features.
6. Inspect explained variance ratios and cumulative explained variance.
7. Visualize the transformed data if appropriate.

## Important Points
- PCA components are combinations of the original features.
- Standardization is often important when feature scales differ.
- Reducing dimensions may simplify data analysis but can discard some information.
- PCA is not a predictive model by itself.

## Libraries
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib

## Result
Run the program to view the transformed data and explained-variance information generated by the code.

## Conclusion
PCA can reduce the number of features while retaining as much variation as possible in the selected components. The usefulness of the reduction depends on the dataset and the variance retained.
